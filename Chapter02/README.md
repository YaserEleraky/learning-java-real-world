# Chapter 2
## Java Fundamentals

This chapter introduces the basic concepts of Java programming through practical examples that demonstrate Java syntax and structure.

### 📦 Included Examples

#### HelloJava.java
- A simple GUI-based "Hello, World!" program that demonstrates the basic structure of a Java application
- Uses Swing components (JFrame, JLabel, JComponent)
- Demonstrates basic graphics programming
- Includes mouse interaction functionality

#### HelloJava2.java
- Enhanced version that shows how to use command-line arguments
- Demonstrates event-driven programming with MouseMotionListener
- Shows how to create custom components in Java
- Implements dynamic text positioning based on mouse movement

### 🛠️ How to Run the Examples

1. Open your Java IDE (IntelliJ IDEA recommended)
2. Open the Chapter 02 project
3. Compile and run either HelloJava or HelloJava2
4. For HelloJava2, pass a custom message as a command-line argument

### 🔑 Key Concepts Covered

- Basic Java syntax and program structure
- Creating a main method and GUI applications
- Using Java Swing for graphical applications
- Printing to the console vs. graphical output
- Using command-line arguments in Java applications
- Implementing event listeners (MouseMotionListener)
- Creating custom components by extending JComponent
- Basic graphics programming with Graphics class
- Understanding component hierarchy in Swing applications
