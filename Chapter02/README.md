# Chapter 2
## Java Fundamentals

This chapter introduces the basic concepts of Java programming. It contains simple examples to help you understand the Java syntax and structure.

### Included Examples
- **HelloJava.java**: A simple "Hello, World!" program that demonstrates the basic structure of a Java application
- **HelloJava2.java**: An enhanced version that shows how to use command-line arguments

### How to Run the Examples
1. Open your Java IDE (IntelliJ IDEA or similar)
2. Open the Chapter 02 project
3. Compile and run either HelloJava or HelloJava2

### Key Concepts Covered
- Basic Java syntax
- Creating a main method
- Printing to the console
- Using command-line arguments
- Java program structure

These examples serve as your first steps in Java programming and will help you set up your development environment for more complex projects in later chapters.
