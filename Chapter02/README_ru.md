# Глава 2
## Основы Java

Эта глава знакомит с базовыми концепциями программирования на Java. В ней приведены простые примеры, которые помогут понять синтаксис и структуру языка Java.

### Примеры
- **HelloJava.java**: Простая программа "Hello, World!", демонстрирующая базовую структуру Java-приложения
- **HelloJava2.java**: Расширенная версия, показывающая как использовать аргументы командной строки

### Как запустить примеры
1. Откройте свою Java IDE (IntelliJ IDEA или аналогичную)
2. Откройте проект Главы 02
3. Скомпилируйте и запустите либо HelloJava, либо HelloJava2

### Основные концепции
- Базовый синтаксис Java
- Создание метода main
- Вывод на консоль
- Использование аргументов командной строки
- Структура Java-программы

Эти примеры станут вашим первым шагом в программировании на Java и помогут настроить среду разработки для более сложных проектов в последующих главах.
